Загрузить слова юнита

Формат: пронумерованный список вида «1) Word - перевод», далее синонимы через запятую, затем строка «Collocations:» и словосочетания на отдельных строках. Если юнит с таким номером уже существует — новые слова добавятся к нему, дубликаты пропускаются.

Массовая загрузка (сразу несколько файлов)

Номер юнита определяется автоматически по названию файла (ищет «Unit N» / «unit N», например «Essential 504 Unit 39.docx» → Unit 39) или по первым строкам текста внутри файла. Название юнита берётся из имени файла. Если для файла не удалось определить номер — он будет пропущен, об этом будет написано в результатах.
